# 0017 — Cloud context reopens the "cloud infrastructure" and "enterprise features" exclusions

`wayfinder/map.md` originally excluded cloud infrastructure and enterprise features from v1, same as it originally excluded auth/sharing/sync before those were reopened one at a time as real needs. The gap this time: a non-technical org member can't configure LLM providers or find useful skills themselves, and an admin configuring it for them requires an account system, org/role model, and hosted config — i.e. exactly what those two bullets excluded. We're reopening both, scoped to that problem, as a new bounded context (`cloud/CONTEXT.md`) rather than folding org/team/role/analytics into the existing single-package daemon (ADR 0001) — Cloud has its own data model, its own deploy target, and doesn't share config/session/event types with the daemon the way the existing `src/` domains do.
