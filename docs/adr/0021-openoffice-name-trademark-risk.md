# `openoffice` name kept despite ASF trademark exposure

The product ships as `openoffice` (npm, GitHub, binary, docs) even though Apache OpenOffice is an ASF trademark in the office-suite space. The name was verified free on npm, renaming now would touch 30+ commits of CONTEXT.md, docs, and tooling, and the products are not in the same space (an LLM agent CLI vs a desktop office suite). Accepted risk — recorded here so the decision is never re-litigated silently. If ASF ever objects, the fallback is the already-reserved `@the-resonance-team/openoffice` scope.
