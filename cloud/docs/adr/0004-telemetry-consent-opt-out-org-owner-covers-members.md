# 0004 — Analytics consent is opt-out, and the Org Owner's acceptance covers all members

A member's Analytics collection is on by default once their Org enables it: the Owner/Admin's consent at Org setup covers members, disclosed at invite time rather than re-collected individually. We chose this over opt-in-per-member because most orgs configuring this for non-technical members expect it to just work, and over opt-in-by-default because opt-out yields materially more usable analytics data. This does not cover the self-hosted OTLP export (root `CONTEXT.md`), which needs no consent flow since data only ever leaves a member's device to an endpoint they configured themselves — nor does it, on its own, authorize collecting document content; the event schema is an allowlist (same posture as issue #14's redaction requirement), not a denylist.
