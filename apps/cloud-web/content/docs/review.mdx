## The Review tab

Pending document and email changes gather here as diffs, grouped by the file they touch.

## Approve or revert

Approve a single edit, approve everything at once, or revert an edit back to the original before it is saved or sent.

## Audit trail

Every approval is logged with who, what and when, so a completed task is fully accountable after the fact.
