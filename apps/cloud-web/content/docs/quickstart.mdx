## Create a workspace

Sign in and create a workspace for a team or project. Workspaces keep sessions, integrations and history scoped and separate.

## Connect an app

Link at least one source — Google Drive is the fastest — so the agent has documents to work with.

## Start a session

Click New session, describe what you need, choose a model, and watch the plan appear step by step.

## Approve the result

Open Review, step through each proposed change, and approve, undo or revert before anything is written back.
