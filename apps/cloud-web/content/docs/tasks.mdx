## Write a good prompt

Name the deliverable, the source and the destination: "Draft the Q3 board deck from the metrics sheet." The clearer the target, the tighter the plan.

## Pick a model

Choose a model per session — heavier reasoning for analysis, faster models for routine cleanup and formatting.

## Watch it work

The stream shows each opened file and proposed edit. Steer mid-task with a follow-up message at any point.
