## Question

Build the terminal UI — the primary interface for openoffice.

### UI framework options

**A. Ink (React for CLI)**

- React component model
- Large ecosystem
- Good for complex layouts
- Heavier than needed

**B. Blessed/termui**

- Traditional TUI framework
- Full terminal control
- Older, less maintained

**C. Custom with ANSI codes**

- Minimal, fast
- Full control
- More work

**D. OpenTUI (what opencode uses)**

- Custom SolidJS-based TUI
- 60fps rendering
- Tight integration with SolidJS
- Requires OpenTUI dependency

### Recommendation

Start with **Ink** for v1. It's the most productive for building CLI UIs with React. opencode uses OpenTUI which is custom and complex — not worth building from scratch.

### What to build

**Chat interface**:

- User input at bottom
- Message history scrollable
- Tool call results inline
- Streaming token display

**Session sidebar**:

- List of sessions
- Create new session
- Switch between sessions

**Status bar**:

- Current agent
- Current model
- Session info

### Implementation skeleton

```tsx
import { render, Box, Text, useInput } from 'ink';

function App() {
  const [messages, setMessages] = useState<Message[]>([]);
  const [input, setInput] = useState('');

  useInput((char, key) => {
    if (key.return && input.trim()) {
      sendMessage(input);
      setInput('');
    }
  });

  return (
    <Box flexDirection="column" height="100%">
      <Box flexGrow={1} flexDirection="column" overflow="hidden">
        {messages.map((msg) => (
          <Message key={msg.id} message={msg} />
        ))}
      </Box>
      <Box borderStyle="round" borderColor="gray">
        <Text> </Text>
        <TextInput value={input} onChange={setInput} />
      </Box>
    </Box>
  );
}
```
